# Créer les comptes Diktéo — 15 min chrono (tout est à copier-coller)

## Étape 0 — Adresse mail (2 min, hPanel Hostinger)
hPanel → Emails → diktéo.fr (ou dikteo.fr) → Créer un compte e-mail → `social@` → mot de passe généré par ton gestionnaire.
Pas encore de domaine ? Utilise ton Gmail + `+dikteo` (ex. `prenom.nom+dikteo@gmail.com`) : ça arrive dans ta boîte, aucune création.
